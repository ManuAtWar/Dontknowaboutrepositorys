# Glutwacht

Ein Arcade-Roguelite im Browser. Du bist die letzte Flamme in einer endlosen Nacht.
Dein Licht ist dein Leben: Jeder Treffer und jede Sekunde in der Dunkelheit kostet Licht.
Öltropfen füllen es wieder auf.

## Spielen

`index.html` im Browser öffnen. Keine Installation, keine Abhängigkeiten.

| Aktion   | Tastatur                | Touch                     |
|----------|-------------------------|---------------------------|
| Bewegen  | WASD / Pfeiltasten      | Ziehen (virtueller Stick) |
| Sprung   | Leertaste / Shift       | Sprung-Knopf oder 2. Finger |
| Upgrade  | 1 / 2 / 3               | Karte antippen            |
| Pause    | Esc / P                 | Pause-Knopf               |
| Ton      | M                       | im Pausemenü              |

## Inhalt

- Automatisches Zielen, du konzentrierst dich aufs Ausweichen
- 12 Upgrades mit Stufen (Funkenregen, Glutnova, Kreisende Glut, Splitterglut …)
- 4 Gegnertypen plus Boss „Der Verschlinger“ alle 2:30 Minuten
- Mottenschwärme, Kettenbonus, Rekord wird lokal gespeichert
- Prozedurale Soundeffekte über die Web Audio API
