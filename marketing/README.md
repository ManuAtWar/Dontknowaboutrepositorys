# ManuAtWar Marketing-Team

Ein Team aus spezialisierten KI-Agenten für den YouTube-Gaming-Kanal ManuAtWar. Es läuft in Claude Code, wenn du dieses Repository öffnest.

## Das Team

| Agent | Aufgabe |
|---|---|
| `marketing-chef` | Strategie, Ziele, Wochen- und Monatsplanung, Prioritäten |
| `trend-scout` | Releases, Updates, Seasons und Trends recherchieren, mit Quellen |
| `titel-seo` | 10 Titelvarianten, Beschreibung, Kapitel, Tags, Hashtags |
| `thumbnail-designer` | 3 Thumbnail-Konzepte mit Text, Farben, Aufbau und Bild-KI-Prompt |
| `skript-autor` | Hooks, Struktur mit Zeiten, Skript oder Stichpunkte, Call-to-Action |
| `shorts-produzent` | 5 Shorts/TikToks/Reels pro Video mit Hook und Untertiteln |
| `community-manager` | Angepinnte Kommentare, Antwortvorlagen, Community-Posts, Discord |
| `analytics-analyst` | YouTube-Studio-Daten auswerten und Maßnahmen ableiten |
| `kooperationen` | Collab-Partner, Sponsoren, Mediakit, Anfrage-Nachrichten |

## Loslegen

1. **`marketing/KANAL.md` ausfüllen.** Das ist das Gedächtnis des Teams: Spiele, Stil, Zielgruppe, Ziele, Links.
2. In Claude Code einen der Befehle nutzen:
   - `/video-launch Neue Season in Spiel X – die 5 besten Strategien` → komplettes Paket für ein Video (Titel, Thumbnail, Hook, Beschreibung, Shorts, Community-Texte) unter `marketing/videos/`
   - `/wochenplan` → Content-Plan für die nächste Woche unter `marketing/planung/`
   - `/kanal-check` → Auswertung deiner YouTube-Studio-Daten
3. Oder einen Agenten direkt ansprechen, z. B. „Lass den thumbnail-designer drei Konzepte für mein nächstes Video machen“.

## Ordner

- `marketing/videos/` – Launch-Pakete pro Video
- `marketing/planung/` – Wochenpläne, Trends, Mediakit
- `marketing/daten/` – CSV-Exporte aus YouTube Studio und Auswertungen

## Spielregeln des Teams

Kein gekauftes Wachstum, keine irreführenden Thumbnails, Werbung immer kennzeichnen und keine erfundenen Zahlen. Die Agenten markieren, was sie annehmen oder nicht wissen.
